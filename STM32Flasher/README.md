# STM32 烧录器 for macOS

一个面向 STM32F103C8T6 和 ST-Link 的原生 macOS 小工具。

产品只围绕一件事设计：选择程序，检测设备，稳定地烧录并校验。

## 功能

- 自动寻找 ST 官方 `STM32_Programmer_CLI`
- 支持 `.hex`、`.bin` 和 `.elf`
- 自动擦除、写入、校验并复位
- 固件大小、地址和命令输出安全限制
- 白色简洁布局，左侧栏可在 180–340px 范围内拖动
- 稳定的资源管理器：左侧只显示完整文件夹树，已打开文件由编辑器标签页管理
- 支持任意深度的“文件夹套文件夹”层级，可一键全部展开或全部收起
- 支持打开工程文件夹、刷新文件列表，并恢复上次打开的文件或文件夹
- 支持关闭当前文件夹；刷新和切换文件不会改变当前标签或列表顺序
- 后台、可取消的文件夹扫描，对所有文件和目录合计执行 2,000 项硬上限
- 构建与检查缓存仅使用临时目录，工程 `build` 目录只保留最终 App
- 支持新建空白 C 程序、打开、打开方式、保存和另存为源码
- 简洁 C 编辑器；高亮在后台有界计算，撤销历史限制为 30 层并按文件隔离
- ARM GCC 编译并自动载入生成的固件
- 全局结果提示，点击窗口任意位置即可关闭
- 自适应代码工具栏，最小窗口宽度下按钮不会竖排或挤压变形
- 修改源码会立即作废旧固件，避免误烧录上一次构建
- 工程内文件构建工程；工程外文件和未命名文件只构建当前编辑器内容
- 保存失败会中止编译，编译期间修改代码会让旧构建结果失效
- 新建文件不会清空资源管理器；退出、切换或打开其他文件前提供未保存代码保护
- 最新编译成功且确认 ST-Link 与 STM32F103 中密度目标后才允许烧录；擦除前再次核验目标
- BIN 写入区间必须完全落在 64 KiB Flash 内，下载与校验均有明确成功证据才报告成功
- 有界日志、命令超时、取消保护和旧任务回调隔离

搜索、Git、插件、内置模板、拆分窗口、接线说明和多主题系统均不属于本产品。

## 依赖

烧录需要安装 ST 官方 STM32CubeProgrammer。代码编译需要本机存在
`arm-none-eabi-gcc`；只使用现成 HEX/BIN/ELF 时不需要 ARM GCC。

## 构建与检查

```bash
zsh ./Scripts/check.sh
```

产物位于 `build/STM32 烧录器.app`。

维护前请阅读 [`ARCHITECTURE.md`](ARCHITECTURE.md)。应用不会上传源码，
不会自动联网安装工具链，也不会在没有用户操作时烧录设备。
