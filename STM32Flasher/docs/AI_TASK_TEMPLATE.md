## 推荐的小任务写法

一次任务尽量只有一个可验收目标。例如：

```text
把 5631BS 单位显示模板改成恒亮数字 8。保持现有接线不变，
ARM GCC 必须 0 errors。只修改模板并构建 Mac 应用，本次不烧录硬件。
```

如果需要烧录，请在同一条任务里明确写“允许烧录”。过去任务中的烧录许可
不会自动延续到新的任务。
